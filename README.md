# 💸 Expense Tracker (MERN Stack)

A modern, full-stack Expense Tracker web application built using the **MERN** stack (MongoDB, Express.js, React with Vite, Node.js). This app allows users to easily log, view, track, and manage their daily expenses with category filters and summary charts.

---

## 🚀 Live Demo

* **Live Application:** [Expense Tracker on Vercel](https://expense-tracker-alpha-six-99.vercel.app)

---

## ✨ Features

* 📝 **Add New Expenses:** Easily record expense title, amount, category, and date.
* 📊 **Summary Cards & Charts:** Visual breakdown of total spending and category summaries using React charts.
* 🔍 **Category Filtering:** Filter expenses dynamically by categories (e.g., Food, Travel, Shopping, Entertainment).
* ⚡ **Lightning Fast:** Powered by **Vite** on the frontend for instant HMR and quick builds.
* 🛡️ **RESTful API:** Secure Express backend with Mongoose ODM connected to MongoDB Atlas.

---

## 🛠️ Tech Stack

### **Frontend (Client)**
* **Library:** React.js 
* **Styling:** Tailwind CSS / CSS Modules
* **HTTP Client:** Axios
* **Icons & Charts:** Lucide React / Recharts / Chart.js

### **Backend (Server)**
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB Atlas
